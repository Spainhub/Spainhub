# Интерфейс (Stage 8)

React + TypeScript + Vite, без тяжёлых UI-библиотек; маршрутизация — react-router. Интерфейс на русском, светлая тема, оранжевый акцент.
Вся бизнес-логика расчётов — на бэкенде (движок P&L); фронтенд только показывает значения и статусы.

## Разделы
| маршрут | что делает |
|---|---|
| `/login` | вход (cookie-сессия, CSRF-токен подставляется автоматически) |
| `/` Дашборд | KPI за период и к предыдущему периоду, динамика по месяцам; нерассчитанные показатели — «—» с причиной, без нулей |
| `/pnl` | P&L: даты, детализация (месяцы/дни/итого), аккаунт, сравнение с предыдущим периодом, сворачиваемые группы, статусы ячеек, источник (импорт/вручную/расчёт), расшифровка строки до записей, блок качества данных |
| `/connections` | аккаунты WB: добавить (токен скрыт), проверить, загрузить за 3 месяца, статус загрузок, повторить, заменить токен, отключить |
| `/expenses` | ручные записи (расходы, корректировки) и себестоимость: шаблон Excel → заполнить → загрузить, ошибки построчно |
| `/settings` | налоговый режим (УСН «доходы» / ОСНО) и ставки |
| `/admin` | только администратор платформы: организации, пользователи, последние загрузки |

Права на фронтенде лишь скрывают лишние действия; фактическая защита — на бэкенде (роли, изоляция организаций).

## Статусы ячеек P&L
`нет данных` — данных нет · `—  ≈ X предв.` — не хватает входов, показана только справочная оценка · `неполно` — посчитано, но есть замечания (подсказка при наведении).

## Деньги
Суммы приходят строками и форматируются без перевода в float (`utils/format.ts`, `utils/decimal.ts`): группы разрядов, запятая, типографский минус, округление half-up.

## Запуск и проверка
```bash
cd frontend
npm install
npm run dev          # http://localhost:5173, /api проксируется на localhost:8000
npm test             # Vitest + Testing Library (49 тестов)
npm run build        # tsc + vite build → dist/
```
Продакшен: статика отдаётся nginx из контейнера `frontend` (`frontend/nginx.conf`, SPA-fallback на index.html), `/api` проксируется на backend.
