# E-commerce Project 1.0 — Apps Script

Замените в проекте Apps Script файлы `Code.gs` и `Index.html` целиком, затем **Развернуть → Новая версия**.

## Столбцы листа «Таблица»
`ID | ID Связи | № | Этап | Задача | Под-задача | Владелец результата | Ответственный | Решающий | Информируемые | От кого получаем инф. | Кому передаем инф. | Старт | Финиш | Статус | Блокер | Кем заблок. | С какого числа | Прогресс | Документ | Результат | Комментарий`

| Что нужно | Чем задаётся |
|---|---|
| Иерархия Этап → Задача → Под-задача | колонка `№` (1 / 1.2 / 1.2.3); если пуста — по колонкам Этап/Задача/Под-задача |
| Связи задача ↔ под-задача, зависимости задача ↔ этап | `ID Связи`: ID строк (любого уровня) через `;` — «зависит от» (константа `LINK_MODE` в `Code.gs`: `depends_on` / `feeds`) |
| Кто кому передаёт информацию | `От кого получаем инф.` / `Кому передаем инф.`: ID строки **или** ФИО/отдел (через `;` или с новой строки) |
| Что именно передаётся | `Результат` строки-источника |

Связь достаточно указать с одной стороны; одинаковые связи объединяются.

## Вкладки
* **Таблица** — иерархия, чипы «← Получаем от» / «→ Передаем».
* **Связи** — Этап → Задача → Под-задача (+/−) с итогами; ⇄ раскрывает входящие/исходящие передачи.
* **Обмен** — по сотруднику: «Мне поступает» / «Я передаю дальше» (кто, что, из какой задачи/этапа в какую, сроки, статус). Только просмотр, в таблицу ничего не пишется.
* **График Ганта** — ⛔ блокеры, ⚡ триггеры, стрелки зависимостей, линия «сегодня».


## Проекты в заголовке
Список берётся из колонки **«Проекты»** листа «Справочник»; выбор — стрелка справа от названия (запоминается в браузере).
Если в листе «Таблица» есть колонка **«Проект»**, строки фильтруются по выбранному проекту.

## Документ
Колонка «Документ» показывает ссылку, вставленную в ячейку Google Таблицы (ссылка на ячейку/часть текста, формула `HYPERLINK`, либо URL в тексте). В веб-версии не редактируется.
