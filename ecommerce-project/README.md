# E-commerce Project 1.0 — Apps Script

Замените в проекте Apps Script файлы `Code.gs` и `Index.html` целиком, затем **Развернуть → Новая версия**.

## Как задаются связи (лист «Таблица»)
| Колонка | Смысл |
|---|---|
| `ID` | уникальный ID задачи / под-задачи |
| `Вход инф.` + `Вход (ID)` | какая информация нужна и **от каких ID** она приходит |
| `Выход инф.` + `Выход (ID)` | какая информация передаётся и **каким ID** |

Несколько ID — через `;` `,` или пробел. Заголовки `Вход ID` и `Вход (ID)` равнозначны. Связь A → B достаточно указать с одной стороны (у A в «Выход» или у B в «Вход»).

## Вкладки
* **Таблица** — иерархия по «№», столбцы «Вход ← от кого» / «Выход → кому» (кликабельные чипы).
* **Сводная связей** — Этап → Задача → Под-задача (+/−) с итогами; кнопка ⇄ раскрывает, что приходит и куда уходит.
* **Обмен** — выбор сотрудника: «Мне поступает» / «Я передаю дальше» (кто, что, из какой задачи, в какую, сроки, статус), галочка «Получено».
* **График Ганта** — ⛔ блокеры, ⚡ триггеры, стрелки зависимостей, линия «сегодня».

Лист **«Обмен»** создаётся автоматически: меню таблицы `E-commerce → Обновить лист «Обмен»` или кнопка во вкладке «Обмен».
Столбцы «Получено» и «Комментарий» при обновлении сохраняются.
