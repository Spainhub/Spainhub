# E-commerce Project 1.0 — Apps Script

Замените в проекте Apps Script файлы `Code.gs` и `Index.html` целиком, затем **Развернуть → Новая версия**.

## Столбцы листа «Таблица»
`ID | ID Связи | № | Этап | Задача | Под-задача | Владелец результата | Ответственный | Решающий | Информируемые | От кого получаем инф. | Кому передаем инф. | Старт | Финиш | Статус | Блокер | Кем заблок. | С какого числа | Прогресс | Документ | Результат | Комментарий`

| Что нужно | Чем задаётся |
|---|---|
| Иерархия Этап → Задача → Под-задача | колонка `№` (1 / 1.2 / 1.2.3); если пуста — по колонкам Этап/Задача/Под-задача |
| Связи задача ↔ под-задача, зависимости задача ↔ этап | `ID Связи`: ID строк (любого уровня) через `;` — «зависит от» (константа `LINK_MODE` в `Code.gs`: `depends_on` / `feeds`) |
| Кто кому передаёт информацию | `От кого получаем инф.` / `Кому передаем инф.`: ID строки **или** ФИО/отдел (через `;` или с новой строки) |
| Что именно передаётся | `Результат` строки-источника |

Связь достаточно указать с одной стороны; одинаковые связи объединяются.

## Вкладки
* **Таблица** — иерархия, чипы «← Получаем от» / «→ Передаем».
* **Связи** — Этап → Задача → Под-задача (+/−) с итогами; ⇄ раскрывает входящие/исходящие передачи.
* **Обмен** — по сотруднику: «Мне поступает» / «Я передаю дальше» (кто, что, из какой задачи/этапа в какую, сроки, статус). Только просмотр, в таблицу ничего не пишется.
* **График Ганта** — ⛔ блокеры, ⚡ триггеры, стрелки зависимостей, линия «сегодня».


## Проекты в заголовке
Список берётся из колонки **«Проекты»** листа «Справочник»; выбор — стрелка справа от названия (запоминается в браузере).
Если в листе «Таблица» есть колонка **«Проект»**, строки фильтруются по выбранному проекту.

## Документ
Колонка «Документ» показывает ссылку, вставленную в ячейку Google Таблицы (ссылка на ячейку/часть текста, формула `HYPERLINK`, либо URL в тексте). В веб-версии не редактируется.

## Лист «Митинг» и вкладка «Митинг»
Столбцы: `ID | № | Этап | Задача | Под-задача | Старт | Финиш | Дата | Статус встречи | Тема встречи | Повестка встречи | Участники встречи | Вопросы | Протокол встречи | Комментарий`.

«№» в листе «Митинг» — порядковый номер встречи (1, 2, 3…), на привязку не влияет.
Привязка встречи к строке «Таблицы»: по названиям `Под-задача` → `Задача` → `Этап` (берётся самый глубокий заполненный уровень; названия должны совпадать с «Таблицей»). Ссылки в «Протокол встречи» / «Повестка встречи» (гиперссылка в ячейке, `HYPERLINK`, URL в тексте) открываются кликом. В «Таблице» появился столбец «Митинги» (число встреч этапа/задачи с вложенными) — клик открывает вкладку с фильтром.
Участники и вопросы разделяются `;` или переносом строки.

## Вкладка «Главная»
* Виджеты: ключевые показатели, прогресс, участники проекта (клик → «Обмен» сотрудника), ближайшие сроки и митинги.
* Блок «Ссылки и заметки» — диапазон **A1:H40** листа «Главная» (текст, ссылки, заливка, жирность, объединённые ячейки, ширины столбцов). Меняйте лист — на странице нажмите «↻ Обновить».

## Пароль для входа
В начале `Code.gs`: `const APP_PASSWORD = '2016';`. Пустая строка `''` — окно входа не показывается. Пароль проверяется на сервере (без него данные не загружаются и ячейки не сохраняются); после входа он помнится до закрытия вкладки, кнопка «🔒 Выйти» — в шапке.

## Вкладка «Митинг» — порядок и календарь
Строки без даты не показываются. Сверху — актуальные (сегодня) и планируемые встречи, ближайшие первыми; ниже — прошедшие, свежие первыми. Дата в одну строку («29 сентября 2026»). Переключатель «☰ Список / 📅 Календарь» (выбор запоминается): в календаре встречи — цветные чипы по статусу, клик по дню открывает карточки встреч этого дня.

## Журнал изменений (лист «Изменения»)
Каждая правка, сделанная **в веб-приложении** (смена статуса, прогресса, комментария и т.д.), записывается строкой в лист «Изменения» (если листа нет — создаётся). Правки, сделанные прямо в Google Таблице, не логируются.
Столбцы: `Дата и время | Кто | Email | Лист | Строка | ID | № | Название | Поле | Было | Стало`. Если на листе уже есть свои заголовки, значения кладутся под совпавшие названия столбцов; если значение не изменилось — записи нет.
«Кто»: имя, которое пользователь вводит один раз при первой правке (запоминается в браузере, меняется кнопкой «👤» в шапке); Email записывается, когда Google передаёт его скрипту (зависит от режима публикации и домена).
