# REPORT · P&L 4 — version 1.0

Интерактивные отчёты (Google Apps Script Web App) по данным Google-таблицы:
P&L по 4 маркетплейсам (WB / Ozon × Kvantum / Azimut), остатки OZ и лист ссылок.

## Структура проекта

```
table-report/
├── src/                    # всё, что загружается в Apps Script
│   ├── Code.gs             # сервер: чтение листов, форматы, LINK-лист
│   ├── Index.html          # каркас страницы
│   ├── Styles.html         # стили
│   ├── Scripts.html        # клиентская логика (таблицы, фильтры, графики)
│   └── appsscript.json     # манифест (V8, доступ Web App)
├── .clasp.json.example     # шаблон для clasp (скопируйте в .clasp.json)
├── .claspignore
├── CHANGELOG.md
└── README.md
```

## Листы Google-таблицы → вкладки

| Лист      | Вкладка            | Содержимое |
|-----------|--------------------|------------|
| `WB&OZ`   | WB & OZ Total      | две диаграммы (выручка — столбцы, маржинальная прибыль — линия с градиентом) и две таблицы: шапки в строках 6 и 11 |
| `OZ_UNIT1`| OZ Unit 1      | шапка в строке 6, «Итого» в строке 7 |
| `OZ_UNIT2`| OZ Unit 2       | то же |
| `WB_UNIT1`| WB Unit 1      | то же + столбцы-даты как мини-графики |
| `WB_UNIT2`| WB Unit 2       | то же |
| `OZPL1`   | OZ Stock 1   | шапка в строке 5, «Итого» в строке 6 |
| `OZPL2`   | OZ Stock 2    | то же |
| `LINK`    | LINK               | диапазон A1:J30 «как в листе», ссылки подсвечены |

Строки выше шапки (1–5 или 1–4) выводятся блоком в том же виде, что и в таблице.
Названия вкладок и номера строк настраиваются в `SHEETS_CONFIG` (`src/Code.gs`).

## Установка

**Вручную:** Extensions → Apps Script в вашей таблице → создайте файлы `Code` (.gs),
`Index`, `Styles`, `Scripts` (HTML) с теми же именами, вставьте содержимое из `src/`,
замените `appsscript.json` (Project Settings → «Show appsscript.json»).
Затем *Deploy → Manage deployments → Edit → New version → Deploy*.

**Через clasp:**
```bash
npm i -g @google/clasp && clasp login
cp .clasp.json.example .clasp.json   # впишите scriptId
clasp push
```

Если проект не привязан к таблице, укажите её ID в `SPREADSHEET_ID` (`src/Code.gs`).

## Возможности

- Сортировка, фильтры по столбцам, общий поиск (в строке вкладок, справа)
- Изменение ширины столбцов (двойной клик по границе — по содержимому), всё в одну строку
- Скрытие/показ столбцов; отдельный фильтр ABC; быстрые фильтры по юнитам
- Отрицательные значения красным; ABC — цветные бейджи; числа/проценты по формату листа
- Мини-графики и графики по датам (WB) с названием товара и SKU
- Печать
