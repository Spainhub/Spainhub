# Oz Sales Report

Google Apps Script: отчёт Ozon о реализации по дням → Google Sheets
(`POST /v1/finance/realization/by-day`, нужна подписка Premium Plus/Pro).

## Установка
1. Создайте Google-таблицу → **Расширения → Apps Script**.
2. Вставьте содержимое `Code.gs` (и при желании `appsscript.json` — «Настройки проекта → Показывать файл манифеста»; поменяйте `timeZone`).
3. Обновите таблицу — появится меню **Ozon Sales**.
4. **Add API key** и **Add ID** (Client-Id из Ozon Seller → Настройки → API-ключи). Когда введены оба значения, скрипт предложит первую загрузку.

## Меню
Add API key · Add ID · Replace API key · Replace ID · Delete key and ID
(удаляет ключи и отключает автообновление, данные на листе остаются) ·
Update now · Enable/Disable auto-update · Status.

## Логика
- Первый запуск: последние **30 дней**. Затем автообновление **раз в 24 часа** (~06:00): заново грузятся последние 3 дня (Ozon правит данные задним числом) — строки этих дат заменяются, остальное накапливается.
- При каждом обновлении удаляются строки старше **3 месяцев**.
- Лист `Ozon Sales`: одна строка = товар за день; блоки «Доставка» и «Возврат» (amount, bonus, commission, … total).
- Ключи хранятся в `UserProperties` (видны только вам). 404 за день = нет данных; 401/403 останавливают загрузку с понятным сообщением.
- Настройки (дни, срок хранения, час запуска) — константа `OZ` в начале `Code.gs`.
