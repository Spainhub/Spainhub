# Oz Sales Report

Google Apps Script: отчёт Ozon о реализации → Google Sheets. Интерфейс на русском.

## Методы Ozon (выбираются автоматически)
| Метод | Тариф | Данные |
|---|---|---|
| `POST /v1/finance/realization/by-day` | Premium Plus / Pro | по дням, не глубже 32 дней |
| `POST /v2/finance/realization` | базовый | по месяцам (отчёт приходит до 5-го числа следующего месяца) |

## Установка
1. Создайте Google-таблицу → **Расширения → Apps Script**.
2. Вставьте `Code.gs` (и `appsscript.json` — «Настройки проекта → Показывать файл манифеста»; задайте свой `timeZone`).
3. Обновите таблицу — появится меню **Отчёт Ozon**.
4. «Добавить API-ключ» и «Добавить ID» (Client-Id и ключ — Ozon Seller → Настройки → API-ключи). Когда введены оба, скрипт предложит первую загрузку.

## Меню
Добавить API-ключ · Добавить ID · Заменить API-ключ · Заменить ID · Удалить ключ и ID
(также отключает автообновление, данные на листе остаются) · Обновить сейчас ·
Включить / Отключить автообновление · Статус.

## Логика
- **Первый запуск:** 3 последних месяца (месячный метод), затем попытка загрузить 30 последних дней дневным методом. Ответ 403 = нет Premium → остаются месячные данные.
- **Раз в 24 часа (~06:00):** пробуем дневной метод (последние 3 дня, строки этих дат заменяются). Нет Premium — обновляются текущий и прошлый месяц месячным методом. Если подписку подключили позже, скрипт сам перейдёт на дневной режим.
- **Без двойного учёта:** если по месяцу есть дневные строки, его месячные строки убираются. Самый ранний месяц окна дневной загрузки частично охвачен — до подключения дневного режима его ранние дни остаются только в месячных данных, которые заменяются дневными (дневной метод не отдаёт данные старше 32 дней).
- **Хранение:** старше 3 месяцев удаляется при каждом обновлении.
- **Лист «Реализация Ozon»:** `Период` (день или 1-е число месяца), `Тип` (День/Месяц), товар, цена, комиссия, блоки «Доставка» и «Возврат». Фильтруйте по `Тип`.
- Ключи в `UserProperties` (видны только вам). Ошибки 401/403 на месячном методе останавливают загрузку с пояснением. Параметры — константа `OZ` в начале `Code.gs`.
