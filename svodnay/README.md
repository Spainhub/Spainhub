# svodnay — выгрузка данных Ozon в Google Таблицы

Скрипт Google Apps Script: забирает данные Ozon Seller API и записывает их на лист `Ozon` в виде обычной таблицы
(строка 1 — заголовки, далее по строке на товар), которую можно использовать в формулах (ВПР, ИНДЕКС/ПОИСКПОЗ, QUERY…).

## Установка
1. В таблице: **Расширения → Apps Script**.
2. Создайте файлы с теми же именами и вставьте содержимое: `Config.gs`, `Errors.gs`, `Http.gs`, `Credentials.gs`, `Menu.gs`,
   `Triggers.gs`, `State.gs`, `Utils.gs`, `SheetStore.gs`, `Ozon.gs`, `Runner.gs`, `Transform.gs`.
3. (Необязательно) Настройки проекта → «Показывать файл манифеста» → вставьте `appsscript.json`.
4. Обновите страницу таблицы — появится меню **Ozon**. При первом действии Google попросит выдать разрешения.

## Меню «Ozon»
| Пункт | Что делает |
|---|---|
| 1. Добавить API-ключ | Сохраняет API-ключ (если уже есть — предложит «Заменить») |
| 1.1 Добавить Seller ID | Сохраняет Seller ID (Client-Id) |
| 2. / 2.1 Заменить … | Меняет сохранённое значение |
| 3. Удалить API-ключ и Seller ID | Удаляет доступы, отключает автообновление, сбрасывает незавершённый запуск (данные на листе остаются) |
| 4. Включить обновление данных → | «Обновить сейчас», автообновление раз в сутки (≈03:00) / каждый час, отключение автообновления, статус, сброс зависшего запуска |

После сохранения обоих значений скрипт делает пробный запрос к Ozon и сообщает, работает ли доступ.

## Как это работает
- **Доступы** хранятся в Script Properties (`OZON_CLIENT_ID`, `OZON_API_KEY`) — вводить повторно не нужно, их используют и триггеры.
  Они видны редакторам скрипта; не давайте права редактора посторонним.
- **Перезапись, а не дубли**: итоговый лист очищается и пишется заново целиком.
- **Лимит 6 минут**: загрузка разбита на короткие шаги (один HTTP-запрос — один шаг), промежуточные данные лежат на скрытых листах `_ozon_cache_*`.
  За ~4 минуты запуск ставится на паузу и продолжается одноразовым триггером; после успеха служебные листы удаляются.
- **Лимиты Ozon**: пагинация (`last_id`/`cursor`, порции по 1000 товаров, 100 отправлений); при HTTP 429, 5xx и сетевых сбоях запуск
  продолжается через ≥ 1 минуту (после 12 неудач подряд останавливается со статусом FAILED — смотрите «Статус»).
- **Автообновление**: триггер работает от имени пользователя, который его включил. Если предыдущий запуск ещё идёт, новый не стартует.
- Лист для вывода по умолчанию `Ozon`; другое имя — Script Property `OZON_SHEET_NAME`. Часовой пояс — `OZON_CONFIG.timezone` в `Config.gs`.

## Колонки
Статус товара · Артикул продавца · sku · Остатки FBS · Остатки FBO · Цена с учётом акции · Комиссии FBO/FBS/rFBS ·
% выкупа (последние 50 единиц за 180 дней) · Эквайринг % · Сумма заказов · Маркетинг (за 14 дней) · Габариты и вес ·
Соинвест Ozon % (FBS, 14 дней) · Категория · Продажи за 28 дней. «Артикул продавца» и «sku» хранятся как текст.
В последней колонке заголовка — время обновления.

## Отличия от исходного скрипта
- Доступы вводятся через меню, а не правкой функции `ozonSetupProperties`.
- Убраны неиспользуемые фазы: возвраты (данные нигде не применялись) и отдельная загрузка FBS за 14 дней (соинвест считается из уже загруженных 180 дней).
- Исправлено: фильтр «Продажи за месяц» сравнивал дату с несуществующим полем (`period.since`) и не отсекал старые заказы.
- В кэш пишутся только нужные поля — ячейка листа не вмещает более 50 000 символов.
- Артикул/sku пишутся как текст через формат ячеек, без видимого апострофа.
